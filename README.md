## Deskripsi Praktikum
Praktikum ini membahas tentang pembuatan kerangka layout web menggunakan **CSS Box Model**, **CSS Floating**, **Clearfix**, serta **HTML5 Semantic Elements** (`<header>`, `<nav>`, `<section>`, `<aside>`, `<footer>`).
